error code, the parallel-call scheduler, `message_end.reasoning`, a scenario file's `runs:` and `recipes`,

tenth arm, and `decodeScenario` no longer refuses an unknown `recipe` name. The record's own shape did not
change, so no record needs migrating and nothing has to be replayed.
